Ranking evaluation

Directional benchmark; not statistically significant. These are measured fixture results, not live API scores. hashing-v1 is lexical hashing retrieval. MiniLM is semantic embeddings.

Dataset

  • 8 synthetic profiles (not real applicants)
  • 32 fixture jobs
  • 256 relevance judgments
  • Profile-level split: 5 validation / 3 held-out test
  • Relevant means label ≥ 2

Terminology

  • TF-IDF — pairwise lexical baseline
  • hashing-v1 — lexical hashing retrieval, not semantic embeddings
  • hybrid — structured weighted ranker
  • sentence-transformers — semantic embeddings (`all-MiniLM-L6-v2`)
