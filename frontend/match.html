Résumé matching

Upload a PDF. Choose the pairwise TF-IDF baseline or the structured hybrid ranker. The overall score is a match score, not a chance of being hired. The résumé is parsed in memory and is not stored.

Ranking mode

Hybrid uses the configured embedding provider. Default hashing-v1 is lexical hashing retrieval, shown as “Lexical vector + structured hybrid”. Sentence-transformers, if configured, is shown as “Semantic + structured hybrid”.

Unused hybrid signals (no location or experience preference) display as N/A, not 0.
